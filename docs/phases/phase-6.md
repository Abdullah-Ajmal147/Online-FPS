# Phase 6 — Progression + social (≈3 weeks)

Goal: reasons to come back, and an easy way to bring friends.

## Tasks

1. Account levels 1–50 with unlock table in data (weapons, attachments, perks).
2. Weapon levels from kills/usage; attachment unlocks per weapon.
3. Daily and weekly challenges (data-driven, server-verified from match stats).
4. Party system: create party, share invite link, ready up, leader queues everyone into one room/team.
5. Recent players list and "add friend" (simple, no presence server yet).
6. Match-result screen shows XP breakdown, level-up, challenge progress.
7. Text chat in lobby/match with a profanity filter; mute player.

## Exit test

- [ ] Three people join a party by link and land on the same team in one match
- [ ] Challenge progress only moves from server-reported stats (tested with a forged client)
- [ ] Unlock table is data; changing it needs no code change

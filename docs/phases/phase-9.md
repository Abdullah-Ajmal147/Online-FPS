# Phase 9 — Live service (ongoing)

Pick from this list per season based on analytics. Don't start any of it before the beta.

- Ranked playlist: MMR (e.g. Glicko-2), placement matches, divisions, seasonal reset, leaderboards
- Round-based attack/defend mode (plant/defuse style, original rules and names)
- Cosmetic store: skins, charms, calling cards; payments via Stripe or the portal's SDK
- Season pass (cosmetic only)
- Mobile touch controls + Poki submission
- New maps every season; limited-time modes and events
- Remote config / feature flags for balance changes without a deploy
- Desktop wrapper (Tauri/Electron) for Steam, only if web retention is strong
- PvE / co-op or extraction: only as a separate, justified project
